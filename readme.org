* Jump-Switch-Flow (JSF)

JSF is a Python package for efficient simulation of stochastic biochemical reaction networks and population models. It implements the /Jump-Switch-Flow/ algorithm, which adaptively combines:

- *Jumps*: Exact stochastic simulation (Gillespie-style) for low-copy-number species
- *Switches*: Automatic transitions between stochastic and deterministic regimes
- *Flow*: Deterministic ODE integration for high-copy-number species

This hybrid approach provides significant computational speedups over pure stochastic simulation while maintaining accuracy, particularly for systems with species spanning multiple scales.

* Quick Start

** Predator-Prey Model

Below is an example simulating a stochastic Lotka-Volterra predator-prey model using JSF.

#+begin_src python
import jsf

x0 = [50, 10]  # [Prey, Predator]

mA = 2.00   # prey birth rate
mB = 0.05   # predation rate
mC = 1.50   # predator death rate

rates = lambda x, _: [mA * x[0],
                       mC * x[1],
                       mB * x[0] * x[1]]

reactant_matrix = [[1, 0],
                   [0, 1],
                   [1, 1]]

product_matrix = [[2, 0],
                  [0, 0],
                  [0, 2]]

stoich = {
    "nu": [
        [a - b for a, b in zip(r1, r2)]
        for r1, r2 in zip(product_matrix, reactant_matrix)
    ],
    "DoDisc": [1, 1],
    "nuReactant": reactant_matrix,
    "nuProduct": product_matrix,
}

t_max = 10
my_opts = {"EnforceDo": [0, 0], "dt": 0.001, "SwitchingThreshold": [30, 30]}

sim = jsf.jsf(x0, rates, stoich, t_max, config=my_opts, method="operator-splitting")

# sim[0] contains trajectories, 
# sim[1] contains time points
# sim[2] contains reaction types (-1 for flow evernts, and then entries relating to the relevant fired reactions)
#+end_src

For more detailed examples, see the =examples/= directory and the documentation.
